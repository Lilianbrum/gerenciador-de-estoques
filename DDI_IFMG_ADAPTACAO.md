# DDI IFMG — adaptação inicial

Este projeto foi selecionado como base para o sistema de controle de estoque da **DDI IFMG**.

## Primeira etapa
- Identificação institucional: **DDI IFMG**.
- A entidade interna `Empresa` foi mantida neste primeiro passo para evitar quebra das relações existentes do projeto; na interface, ela passa a ser apresentada como **Instituição**.
- A lógica comercial existente será adaptada gradualmente para inventário institucional, preservando o funcionamento da base antes de remover módulos.

## Próxima etapa
Adaptar o cadastro e a listagem de produtos para inventário institucional, eliminando dependências de preço/venda e acrescentando os campos necessários ao patrimônio/estoque da DDI IFMG.
